# ============================================================
# 帧字符覆盖配置文件
# 可放在两个位置：
#   1. 全局：与 start.exe 同目录的 override.txt，应用于所有歌曲
#   2. 单独：放在每个歌曲目录下，与 config.ini 同级，只对该歌曲生效
#      若与全局配置重叠（相同 帧表达式+行表达式+列表达式），则单独配置覆盖全局配置
#      全局与单独的条目都同样受 protected 参数控制（protected=1 才不可跳帧）
# 条目以换行分割（每行一个条目），格式：每行 "帧表达式 行表达式 列表达式 字符 [protected] [color]"
#
# 帧/行/列表达式均支持四种形式：
#   1. 单值：100             只在第100帧（或第100行/第100列）应用
#   2. 区间：100-200         在第100到200帧（或行/列，含首尾）都应用
#   3. 取模：%2==0           帧号（行号/列号）模2等于0的值（0,2,4,6...）
#                            %3==1    模3等于1的值（1,4,7,10...）
#   4. 取模+区间：%2==0(10-20)  在10~20之间且模2等于0的值（10,12,14,16,18,20）
#     - 帧表达式里的取模针对帧号；行/列表达式里的取模针对行号/列号
#     - 取模+区间：括号内限定范围（含首尾），适用于帧/行/列
#
# 行/列：0-based，控制台坐标；可用表达式一次覆盖多行多列
# 字符：要覆盖的字符（支持 ASCII、中文、表情符号，可较长）。
#   若字符含空格（如 "hello world"），请用英文双引号包裹：列表达式 "字符"
#   （引号内的空格会原样保留；引号后仍可写 protected 和 color）
# protected（可选）：
#   1 = 该帧设为受保护帧，跳帧机制不会跳过这些帧
#   0 或不填 = 普通覆盖，渲染慢时可能被跳帧跳过
# color（可选）：覆盖字符的 RGB 颜色，格式 "R,G,B"（每个 0-255），如 255,0,0 为红色。
#   对多格宽覆盖（中文/表情/长文本）的所有字符格统一应用该颜色；
#   不填则使用原始帧中该位置的字符颜色（继承原色）。
#   注意：若只想设颜色不想保护，请写作 "... 字符 0 R,G,B"。
#
# 建议：应避免使用大段带保护覆盖（会逐帧读写屏幕缓冲区、拖慢渲染），
#       并启用帧保护（protected=1）以免被跳帧机制跳过造成闪烁。
#
# # 开头为注释，空行忽略
# ============================================================

# 示例1：在第100帧的第5行第10列显示星号（不保护，可能被跳帧跳过）
# 100 5 10 ★

# 示例2：在第100到200帧的第3行第15列显示中文（受保护，不可跳过）
# 100-200 3 15 你好 1

# 示例3：所有偶数帧的第0行第0列显示A（不保护）
# %2==0 0 0 A

# 示例4：帧号模3等于1的帧显示B（受保护）
# %3==1 0 1 B 1

# 示例5：第100帧第5行第10列显示红色星号（受保护 + 颜色 255,0,0）
# 100 5 10 ★ 1 255,0,0

# 示例6：第200帧第2行第5列显示绿色（颜色 0,255,0）但不保护
# 200 2 5 * 0 0,255,0

# 示例7：行/列也用表达式：第100-200帧中，第10到20行的第0列显示竖线（受保护）
# 100-200 10-20 0 | 1

# 示例8：行取模：第100-200帧中，每10行（0,10,20...）的第0列显示+（不保护）
# 100-200 %10==0 0 +

# 示例9：字符含空格，用双引号包裹："hello world"（受保护）
# 100 5 10 "hello world" 1

# 示例10：字符含空格 + 颜色（不保护）
# 100 5 10 "你好 世界" 0 0,255,0

# 示例11：取模+区间：第10~20帧中的偶数帧（10,12,14,16,18,20）的第5行第10列显示★
# %2==0(10-20) 5 10 ★
